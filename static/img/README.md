# Recursos visuales

`culinary-hero.webp` es una imagen ilustrativa creada con la herramienta integrada
de imagegen y convertida a WebP (1536 × 1024, 196456 bytes) para la primera portada.
La portada actual usa la foto de hamburguesa de [food/](food/README.md).
`kitchen-plate.svg` y `favicon.svg` son gráficos originales del proyecto.
